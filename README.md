# Hospital365 — Bilingual Medical Tourism Site

Astro 5 + Tailwind 4 + TypeScript. Static, pre-rendered, bilingual (EN + TR).
Deployed to Vercel. No client-side JS except a tiny vanilla mobile menu toggle.

## Images to replace

All images are SVG placeholders in `public/images/`. Replace each with a real
JPG photo, then update the extension in these data files:

| Placeholder file              | Used by                              | Update in                |
|-------------------------------|--------------------------------------|--------------------------|
| `public/images/hero-urmia.svg`| EN + TR Urmia city pages             | `src/data/cities.ts`     |
| `public/images/hero-tabriz.svg`| EN Tabriz city page                 | `src/data/cities.ts`     |
| `public/images/hero-tehran.svg`| EN Tehran city page                 | `src/data/cities.ts`     |
| `public/images/hero-shiraz.svg`| EN Shiraz city page                 | `src/data/cities.ts`     |
| `public/images/hero-fertility.svg`| EN + TR fertility treatment pages | `src/data/treatments.ts` |
| `public/images/hero-cosmetic.svg`| EN + TR cosmetic surgery pages    | `src/data/treatments.ts` |
| `public/images/hero-dental.svg`| EN dental treatment page            | `src/data/treatments.ts` |
| `public/images/blog-rhinoplasty.svg`| EN rhinoplasty + TR burun posts | `src/data/blog.ts`      |
| `public/images/blog-ivf.svg`  | EN IVF + TR tup-bebek posts          | `src/data/blog.ts`       |

For each: drop the real `.jpg` into `public/images/`, then change the
corresponding `.svg` to `.jpg` in the data file. Also update `src/layouts/Layout.astro`
line 39 if you replace the MedicalBusiness image.

## Build

```sh
npm install
npm run build    # outputs to dist/ and .vercel/output/
```

## SEO

- `sitemap-index.xml` + `sitemap-0.xml` auto-generated by @astrojs/sitemap
- `robots.txt` in `public/`
- hreflang EN↔TR on every page via `<link rel="alternate">`
- JSON-LD: MedicalBusiness (site-wide), BreadcrumbList (every page),
  FAQPage (FAQ + treatment/city/blog pages), Service (treatment pages),
  BlogPosting (blog posts)
